01 — Principe

Le principe des feuilles de style

Les feuilles de style CSS (Cascading Style Sheets) sont des ajouts de code au langage HTML qui prennent en charge la présentation du document. Le concept repose sur la séparation du contenu et de la présentation.

Le rôle du HTML se limite à la structure de la page. Presque tous les éléments de présentation (attributs HTML comme border, balise <font>…) ont disparu en HTML5.

Copier<!-- ❌ Ancien HTML 4 : présentation dans le HTML --> <h1><font color="green">Titre</font></h1> <!-- ✅ HTML5 moderne : style en CSS --> <h1 style="color: red">Titre</h1>
L'avantage majeur

Modifier un style dans une feuille CSS unique, et ce sont des centaines de pages qui voient leur présentation mise à jour instantanément. Impossible à faire si le style est écrit directement dans chaque balise HTML.

03 — Intégration

Intégrer les styles CSS

Il existe 3 façons d'intégrer du CSS, chacune avec une portée et une priorité différente.

1 — Style en ligne (le plus prioritaire)

Directement dans la balise HTML avec l'attribut style. À éviter : ne respecte pas la séparation contenu/présentation et rend les mises à jour très laborieuses.

Copier<h1 style="color: red;">Titre en rouge</h1> <h1 style="font-style: italic;">Titre en italique</h1>
Rendu — style en ligne
Titre en rouge (style="color:red")
Titre en italique
Titre en style normal (défaut)

2 — Style interne

Dans une balise <style> dans le <head>. S'applique à toutes les balises de la page. Le style en ligne reste prioritaire.

Copier<!-- Dans le <head> --> <style> h1 { color: red; } </style> <!-- Dans le <body> --> <h1>Titre rouge (style interne)</h1> <h1 style="color: blue;">Titre bleu (style en ligne, prioritaire)</h1>

3 — Style externe (recommandé)

Un fichier .css séparé lié à toutes les pages HTML. Portée maximale. Respecte parfaitement la séparation contenu/présentation. Un fichier .css ne contient que des règles CSS, jamais de balises HTML.

Copier<!-- Dans le <head> de chaque page HTML --> <link href="style.css" rel="stylesheet" type="text/css"/>

Les 4 niveaux de style

Le style final appliqué est la somme de tous les niveaux, du plus global au plus prioritaire :

Style par défaut du navigateur
priorité la plus basse
+ Style externe (.css)
s'ajoute au défaut
+ Style interne (<style>)
écrase l'externe en cas de conflit
+ Style en ligne (style="...")
priorité maximale
04 — Déclaration

La déclaration de style CSS

Une déclaration de style est composée du binôme propriété : valeur ;. Elle se termine toujours par un point-virgule.

Copier/* Structure d'une règle CSS */ sélecteur { propriété1: valeur; propriété2: valeur; propriété3: valeur; } /* Exemple concret */ h1 { color: red; text-decoration: underline; background-color: yellow; }

Les propriétés identifient ce qui sera stylisé : police (font-*), texte (text-*), arrière-plan (background-*), bordures (border-*)…

Les valeurs s'expriment par un mot-clé (red), un pourcentage (80%), une grandeur (16px), ou même une fonction (rgb()).

Syntaxe — point-virgule obligatoire

Chaque déclaration doit se terminer par un ;. Oublier un point-virgule est l'une des erreurs les plus fréquentes en CSS — elle peut annuler toutes les déclarations suivantes dans le même bloc.

05 — Sélecteurs

Les sélecteurs CSS

Les sélecteurs indiquent où s'appliquent les styles. Quelques règles : pas d'espaces ni de caractères spéciaux dans les noms, pas de début par un chiffre, tout en minuscules de préférence.

Sélecteur de type
balise { ... }
Cible toutes les balises de ce type dans le document. Priorité la plus basse des 3.
Sélecteur de classe
.nom-classe { ... }
Cible tous les éléments ayant class="nom-classe". Réutilisable sur n'importe quelle balise. Prioritaire sur le type.
Sélecteur d'identification
#mon-id { ... }
Cible l'élément unique ayant id="mon-id". Un id ne peut apparaître qu'une seule fois par page. Prioritaire sur la classe.
Sélecteur multiple
h1, h2, h3 { ... }
Applique le même style à plusieurs sélecteurs. Les séparer par des virgules.

Sélecteur de type

Copier/* Cible tous les <p> de la page */ p { background-color: red; }

Sélecteur de classe

Copier/* Classe simple — utilisable sur toute balise */ .rouge { background-color: red; color: white; font-size: 1.5em; } /* Classe liée à une balise spécifique */ blockquote.rouge { background-color: red; color: white; } /* Plusieurs classes sur un même élément HTML */ /* <p class="rouge souligne"> */ .souligne { text-decoration: underline; } p.rouge.souligne { text-decoration-color: yellow; }
Rendu — classe .bleue sur h1 et p
h1 avec class="bleue"
p avec class="bleue"

La même classe produit un rendu légèrement différent car le style s'ajoute au style par défaut de chaque balise.

Sélecteur d'identification

Copier/* Cible l'élément unique avec id="rouge" */ #rouge { background-color: red; color: white; } /* Combinaison id + class (pas de conflit) */ /* <p id="rouge" class="taille"> */ #rouge { background-color: red; } .taille { font-size: 25px; } /* → style = défaut + id + class */ /* Sélecteur multiple */ h1, div.contenu { color: blue; background-color: white; }
Ordre de priorité des sélecteurs

En cas de conflit : id > class > type. L'id est toujours prioritaire sur la classe, qui est prioritaire sur le type de balise. Et !important passe devant tout le monde.

06 — Cascade

Notions de cascade

En cas de conflit entre deux règles CSS, c'est la règle la plus prioritaire qui l'emporte. L'ordre de priorité, du plus bas au plus haut :

Copier/* 1. Style externe — fichier style.css */ h1 { text-decoration: overline; color: green; } /* 2. Style interne — dans <style> du <head> */ h1 { text-decoration: underline; color: blueviolet; /* écrase le green */ } /* 3. Style en ligne — sur la balise directement */ <h1 style="color: orange;"> → orange (prioritaire) </h1> /* 4. !important — passe devant tout */ h1 { color: green !important; }
!important

!important force une propriété à être prioritaire sur toutes les autres, même sur le style en ligne. À utiliser avec parcimonie — un abus de !important rend le CSS très difficile à maintenir.

07 — Héritage

La notion d'héritage

Le HTML est basé sur le modèle Parent-Enfants. Toute balise a forcément un parent, sauf <html>. Ce modèle entraîne le principe d'héritage CSS : chaque élément enfant reçoit les styles de son parent.

C'est d'ailleurs de là que vient le nom CSS = Cascading Style Sheets — les styles se propagent en cascade du parent vers ses enfants.

Exemple — héritage du gras et de l'italique
Une phrase en gras (1) , avec des parties en italique (2) et du code (3)

La balise <code> hérite du gras de <b> ET de l'italique de <i>, en plus de son propre style (police monospace).

Copier/* Appliquer une couleur sur html la propage sur TOUS les enfants */ html { color: brown; /* héritable → propagé à body, div, p, span… */ } /* Attention : certaines propriétés ne sont PAS héritables */ div { width: 500px; /* non héritable → les enfants ne récupèrent pas 500px */ border: 1px solid black; /* non héritable */ }
Propriétés héritables

Les propriétés de texte (color, font-*, text-*, line-height…) sont héritables. Les propriétés de boîte (width, height, border, margin, padding…) ne le sont généralement pas. Vérifiez sur developer.mozilla.org pour chaque propriété.

08 — Unités

Les unités de mesure

On distingue les valeurs absolues (constantes quel que soit l'écran) et les valeurs relatives (qui varient selon le contexte).

Valeurs absolues

UnitéNomEquiv.
ptpoint72pt = 1in
pcpica1pc = 12pt
mmmillimètre10mm = 1cm
cmcentimètre1cm = 10mm
ininch (pouce)1in = 2.54cm

Valeurs relatives

UnitéDescription
emRelatif à la taille de police parente
exHauteur de la minuscule x de la police
pxPixel — dépend de la résolution d'écran
%Pourcentage par rapport au parent
Recommandation

Pour le web, préférez les unités relatives (em, %) aux unités absolues pour un meilleur rendu sur tous les écrans. Les unités absolues (cm, mm…) sont plutôt adaptées à l'impression.
