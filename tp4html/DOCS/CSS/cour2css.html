01 — Boîtes

La notion de boîtes

Par défaut, chaque élément HTML est une boîte avec un comportement d'affichage (display) défini. On distingue deux grandes catégories :

TypeComportementExemples
Bloc (block) Prend toute la largeur disponible. S'adapte en hauteur selon son contenu. Le bloc suivant se place en dessous. Impossible d'avoir 2 blocs côte à côte. <p>, <div>, <h1>…
Ligne (inline) Prend uniquement la place nécessaire en largeur. Si la boîte suivante est en ligne, elle se colle à la première. <span>, <a>, <cite>…
Démo — blocs vs inline
Boîte BLOC — prend toute la largeur
Boîte BLOC suivante — se place en dessous
Inline Inline Inline — se collent côte à côte
Positionnement static

C'est le comportement par défaut de toutes les boîtes. Les éléments suivent le flux normal : de gauche à droite puis de haut en bas, dans l'ordre de déclaration HTML. Les propriétés top, right, bottom, left et z-index n'ont aucun effet en mode static.

02 — Couleurs

Les couleurs du texte et du fond

Deux propriétés essentielles : color pour la couleur du texte et background-color pour la couleur d'arrière-plan. Par défaut le texte est noir pour toutes les balises.

Copier/* Modifier la couleur pour toute la page */ body { color: red; /* héritage → propagé à p, h1, a… */ } /* Couleur de fond sur un paragraphe */ p { background-color: yellow; } /* Les 3 notations principales */ h1 { color: #2563eb; } /* hexadécimal */ h2 { color: rgb(37, 99, 235); } /* rgb */ h3 { color: rgba(37, 99, 235, 0.6); } /* rgba */
Astuce héritage

Pour changer la couleur du texte sur tout le site, modifiez uniquement body { color: ... }. Le principe d'héritage propagera automatiquement cette couleur à toutes les balises enfants (<p>, <h1>, <a>…).

03 — Texte

Les propriétés de texte

La famille text-* regroupe de nombreuses propriétés. Certaines sont des raccourcis qui se déclinent en sous-propriétés plus précises.

PropriétéValeurs courantesEffet
text-alignleft | right | center | justifyAlignement horizontal du texte dans un bloc. Pas d'effet sur les éléments inline.
text-align-lastleft | center | rightAlignement de la dernière ligne d'un texte justifié.
text-decorationunderline | overline | line-throughRaccourci pour décorer le texte (ligne sous, sur ou à travers).
text-decoration-colorcouleur | currentColorCouleur de la décoration.
text-decoration-lineunderline | overline | line-throughPosition de la décoration — cumulable.
text-decoration-stylesolid | dashed | dotted | wavy | doubleStyle de la ligne de décoration.
text-indentpx, em, %Retrait de la première ligne d'un paragraphe.
text-transformuppercase | lowercase | capitalizeCasse du texte affiché (sans modifier le HTML).
text-shadowx y blur couleurOmbre portée sur le texte.
writing-modehorizontal-tb | vertical-rlOrientation du texte (horizontal ou vertical).
Copier/* Alignements et décoration */ #p1 { text-align: center; } #p2 { text-align: justify; text-align-last: center; } #p3 { text-align: right; text-decoration: solid underline chartreuse; /* raccourci */ } /* Propriétés détaillées */ .overline { text-decoration-style: wavy; text-decoration-line: overline; text-decoration-color: red; } /* Ombre, majuscules, interligne */ #p4 { text-transform: uppercase; text-shadow: 3px -4px 1px rgba(204, 232, 223, 1); line-height: 2em; } /* Retrait première ligne + orientation verticale */ #p5 { text-indent: 10em; writing-mode: vertical-rl; text-orientation: mixed; }

06 — Séparateur

Style sur <hr>

La balise <hr> (ligne horizontale) peut être entièrement stylisée avec CSS. Par défaut elle affiche un trait gris ordinaire.

Copier/* hr simple coloré */ hr.bleu { border: none; border-top: 4px solid #2563eb; } /* hr en pointillés */ hr.pointilles { border: none; border-top: 2px dashed #2563eb; } /* hr avec dégradé */ hr.degrade { border: none; height: 4px; background: linear-gradient(to right, #2563eb, #7c3aed, #16a34a); }

07 — Progression

Style sur <progress>

La balise HTML <progress> affiche une barre de progression. Elle se stylise avec des pseudo-éléments CSS spécifiques selon le navigateur.

Copier<!-- HTML --> <progress value="70" max="100"></progress> /* CSS — WebKit (Chrome, Safari) */ progress::-webkit-progress-bar { background: #e2eafc; } progress::-webkit-progress-value { background: #2563eb; } /* CSS — Firefox */ progress::-moz-progress-bar { background: #2563eb; } /* Propriétés communes */ progress { width: 100%; height: 18px; border: 2px solid #0d1b3e; border-radius: 0; }

08 — Autres propriétés

Autres propriétés d'espacement

Ces propriétés permettent d'affiner les espacements entre lettres, lignes et mots, ainsi que la gestion de la césure.

PropriétéValeursDescription
letter-spacingpx, emEspacement entre chaque lettre du texte
line-heightpx, em, nombreEspacement entre les lignes (interligne)
word-spacingpx, emEspacement entre les mots
hyphensnone | manual | autoGestion de la coupure des mots en fin de ligne. Le caractère HTML &shy; indique manuellement où couper.
Copierp { letter-spacing: 0.1em; /* espace entre lettres */ line-height: 2em; /* double interligne */ word-spacing: 0.3em; /* espace entre mots */ hyphens: auto; /* césure automatique */ } /* Césure manuelle avec &shy; en HTML */ <p>Anti&shy;constitution&shy;nellement</p>
