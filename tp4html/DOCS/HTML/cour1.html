01 — Introduction

Qu'est-ce que le HTML ?

Le HTML (HyperText Markup Language) est le langage de balisage standard pour créer des pages web. Il décrit la structure d'une page à l'aide d'un ensemble d'éléments appelés balises.

Ce n'est pas un langage de programmation — vous n'allez pas écrire de logique ou d'algorithmes. HTML est un langage de description : il dit au navigateur ce que chaque partie de votre contenu représente.

À retenir

HTML structure le contenu. CSS le met en forme. JavaScript le rend interactif. Ces trois langages fonctionnent ensemble pour créer le web moderne.

02 — Structure

Structure d'un document HTML

Tout document HTML valide suit une structure de base précise. Chaque partie a un rôle bien défini que le navigateur interprète.

Copier <!DOCTYPE html> <!-- Déclare la version HTML5 --> <html lang="fr"> <head> <!-- Métadonnées (invisibles) --> <meta charset="UTF-8"> <title>Titre de la page</title> </head> <body> <!-- Contenu visible --> <h1>Titre principal</h1> <p>Un paragraphe de texte.</p> </body> </html>

La balise <!DOCTYPE html> indique au navigateur qu'il s'agit d'un document HTML5. La balise <html> englobe tout le contenu. <head> contient les informations sur le document, et <body> contient ce qui est visible à l'écran.

03 — Balises

Les balises essentielles

Une balise HTML s'écrit entre des chevrons < >. La plupart des éléments ont une balise ouvrante et une balise fermante (précédée d'un /).

<h1> → <h6>
Titres hiérarchiques, du plus important (h1) au plus petit (h6)
<p>
Paragraphe de texte — l'unité de base du contenu
<a>
Hyperlien vers une autre page ou ressource
<img>
Image — balise auto-fermante, sans contenu interne
<ul> / <ol>
Listes non-ordonnées (puces) et ordonnées (numéros)
<div> / <span>
Conteneurs génériques pour regrouper des éléments
04 — Attributs

Les attributs HTML

Les attributs fournissent des informations supplémentaires sur un élément. Ils se placent dans la balise ouvrante, sous la forme nom="valeur".

Copier <!-- Lien avec href et target --> <a href="https://exemple.fr" target="_blank"> Ouvrir le site </a> <!-- Image avec src et alt obligatoire --> <img src="photo.jpg" alt="Description de l'image"> <!-- Paragraphe avec id et class --> <p id="intro" class="lead"> Texte important. </p>
Accessibilité

L'attribut alt sur les images est obligatoire pour l'accessibilité. Il est lu par les lecteurs d'écran pour les personnes malvoyantes.

05 — Exercice

Exercice pratique

Créez un fichier index.html et reproduisez la structure suivante. Ouvrez-le dans votre navigateur pour voir le résultat.

Copier <!DOCTYPE html> <html lang="fr"> <head> <meta charset="UTF-8"> <title>Ma première page</title> </head> <body> <h1>Bonjour, je m'appelle [Votre nom]</h1> <p>Je suis en train d'apprendre le HTML.</p> <h2>Mes hobbies</h2> <ul> <li>La lecture</li> <li>La musique</li> <li>Le code</li> </ul> </body> </html>
