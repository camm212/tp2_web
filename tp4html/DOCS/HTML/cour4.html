Les tableaux HTML & CSS

La balise <table>

Créez des tableaux de données structurés, maîtrisez la fusion de cellules, les sélecteurs hiérarchiques et la mise en forme CSS des tableaux.

// structure d'un tableau
<table>
  <thead>
    <tr>
      <th>Nom</th>
      <th>Valeur</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td colspan="2">Fusionné</td>
    </tr>
  </tbody>
  <tfoot>
    <tr><td>Pied</td></tr>
  </tfoot>
</table>

01 — Introduction

Les tableaux en HTML5

En HTML5, les tableaux sont exclusivement réservés à la présentation de données. Ils ne doivent pas être utilisés pour réaliser la mise en page d'un site — c'est le rôle du CSS.

À ne pas confondre

Les tableaux HTML servent à présenter des données structurées (comme un tableur). Ne pas confondre avec les tableaux/arrays des langages de programmation (C, Java…). Depuis HTML4, les attributs de présentation (width, border, cellpadding…) sont supprimés — tout doit passer par le CSS.

02 — Balises de base

Les balises du tableau

Un tableau <table> contient des lignes <tr> (table row), qui contiennent des cellules <td> ou des en-têtes <th>.

<tr>Ligne du tableau (table row)
<td>Cellule de données (table data)
<th>Cellule d'en-tête — texte en gras et centré par défaut
<caption>Légende du tableau, placée après <table>
<colgroup>Groupement de colonnes pour mise en forme CSS
<thead>En-tête logique du tableau
<tbody>Corps logique du tableau
<tfoot>Pied logique du tableau

03 — Fusion

Fusion de cellules

Les attributs colspan et rowspan permettent de fusionner des cellules horizontalement ou verticalement.

AttributDirectionExemple
colspan="x"Horizontale — fusionne x colonnes<td colspan="3">
rowspan="x"Verticale — fusionne x lignes<td rowspan="2">
Copier<!-- colspan : fusion horizontale --> <table> <tr> <td colspan="3">Titre sur 3 colonnes</td> </tr> <tr> <td>A</td> <td>B</td> <td>C</td> </tr> </table> <!-- rowspan : fusion verticale --> <table> <tr> <td rowspan="2">1</td> <td>2</td> <td>3</td> </tr> <tr> <td>5</td> <td>6</td> </tr> </table>

Accessibilité — attribut scope

Pour les tableaux à double entrée, utilisez scope="col" sur les en-têtes de colonne et scope="row" sur les en-têtes de ligne. Cela associe correctement les données à leurs en-têtes pour les lecteurs d'écran.

04 — Structure

Structurer son tableau

Les balises <thead>, <tbody> et <tfoot> structurent logiquement le tableau. Elles n'affectent pas le visuel mais améliorent la sémantique, l'accessibilité et permettent un ciblage CSS précis.

Ordre à respecter

L'ordre doit toujours être : <thead> → <tbody> → <tfoot>. Le <tfoot> peut contenir des remarques, totaux ou légendes de bas de tableau.

Copier<table> <thead> <tr> <th colspan="2">Titre du tableau</th> </tr> </thead> <tbody> <tr> <td>colspan</td> <td>fusion de colonnes</td> </tr> <tr> <td>rowspan</td> <td>fusion de lignes</td> </tr> </tbody> <tfoot> <tr> <td colspan="2">Pied de tableau</td> </tr> </tfoot> </table>
05 — Colgroup

La balise <colgroup>

<colgroup> permet de grouper des colonnes pour leur appliquer un style CSS commun. Elle se place juste après <table> (ou <caption>) et avant les lignes <tr>. L'attribut span="x" définit le nombre de colonnes groupées.

Copier<table> <!-- 1re colonne en cyan, 2 suivantes en bisque --> <colgroup span="1" style="background-color: cyan"></colgroup> <colgroup span="2" style="background-color: bisque"></colgroup> <tr> <td>1</td> <td>2</td> <td>3</td> </tr> <tr> <td>4</td> <td>5</td> <td>6</td> </tr> </table>

06 — CSS & Héritage

Bordures et héritage CSS

Un principe fondamental du CSS : les éléments enfants héritent des propriétés de leur parent. Mais toutes les propriétés ne sont pas héritables !

Propriétés héritables vs non-héritables

color est héritable → se propage automatiquement aux enfants. border n'est pas héritable → doit être répétée sur chaque élément ciblé. La balise <tr> ne peut pas recevoir de bordure.

Copier/* color héritée par td et th, border non */ #T1 { color: red; border-style: groove; /* appliqué uniquement sur <table> */ } /* Pour bordurer les cellules : répéter sur td/th */ #T1 td, #T1 th { /* sélecteur hiérarchique */ border-style: groove; } /* Style différent pour chaque tableau */ #T2 td, #T2 th { border-style: dotted; }
07 — Sélecteurs

Les sélecteurs hiérarchiques CSS

Les sélecteurs hiérarchiques permettent de cibler un élément selon sa position dans l'arbre HTML.

SyntaxeNomDescription
A B Descendants Sélectionne tout élément B descendant d'un élément A (à n'importe quelle profondeur)
A > B Enfants directs Sélectionne tout élément B enfant direct d'un élément A uniquement
A + B Frère adjacent Sélectionne tout élément B immédiatement précédé d'un élément A (même niveau)

Exemple A B — tous les descendants

Copier/* Tous les <p> dans une <div>, même imbriqués */ div p { color: white; background-color: black; }

Exemple A > B — enfants directs seulement

Copier/* Uniquement les <p> directement dans <div> */ div > p { color: white; background-color: black; }

Exemple A + B — frère adjacent

Copier/* Le <p> qui suit immédiatement une <div> */ div + p { color: white; background-color: black; }
08 — Pseudo-classes

Pseudo-classes de sélection

Ces pseudo-classes sont particulièrement utiles pour la mise en forme de tableaux, notamment pour alterner les couleurs de lignes.

Pseudo-classeDescription
:rootÉlément racine du document (<html> en HTML5)
:emptyÉléments vides sans enfants
:only-childEnfant unique (sans frère)
:first-childPremier élément enfant
:last-childDernier élément enfant
:nth-child(n)Le nième enfant — accepte un nombre, even (pairs) ou odd (impairs)
:nth-last-child(n)Le nième enfant en partant de la fin
:first-of-typePremier élément de ce type
:last-of-typeDernier élément de ce type
:nth-of-type(n)Le nième élément de ce type
Copier/* Lignes alternées + en-tête colorée */ #T3 tr:first-child { background-color: brown !important; /* prioritaire */ } #T3 tr:nth-child(even) { background-color: beige; } #T3 tr:nth-child(odd) { background-color: burlywood; } #T3 td:first-child { background-color: white; /* 1re colonne blanche */ }
Le mot-clé !important

!important force l'application d'une propriété en priorité sur toutes les autres règles CSS. Dans l'exemple ci-dessus, la couleur brown de la première ligne passe avant les couleurs even/odd. À utiliser avec parcimonie.

09 — Autres propriétés CSS

Propriétés CSS spécifiques aux tableaux

Centrage, largeur et bordures

Copier/* Tableau centré, 80% de largeur, texte centré */ #tableau { width: 80%; margin: auto; text-align: center; } /* Coller les bordures des cellules */ #tableau { border-collapse: collapse; /* supprime l'espace entre cellules */ } /* Espacer les cellules */ #tableau { border-spacing: 5px; /* espace entre cellules */ }

Hauteur, largeur fixe et alignement vertical

Copier/* Largeur uniforme des colonnes */ #tableau { height: 200px; table-layout: fixed; /* colonnes de largeur égale */ } /* Alignement vertical du contenu des cellules */ #tableau td, #tableau th { vertical-align: top; /* top | middle (défaut) | bottom */ } /* Position de la légende */ #tableau { caption-side: bottom; /* top (défaut) ou bottom */ }
