01 — Introduction

La balise <a>

L'essence même du Web est de pouvoir naviguer sur différentes pages en suivant des liens hypertextes. La balise utilisée est <a>, qui signifie ancre.

Un lien peut pointer vers :

  • Un endroit de la page en cours
  • Une autre page du même site
  • Une page d'un autre site sur le Web
  • Une adresse électronique
  • Un fichier à télécharger
  • Un numéro de téléphone
Style par défaut des liens

Par défaut, les liens apparaissent soulignés et bleus (non visité), pourpres (visité) et rouges (actif). Ces styles peuvent être modifiés en CSS.

02 — Chemins

Chemins absolus et relatifs

Le format d'écriture des liens est crucial. Une erreur classique est de référencer une page par son chemin physique — ce qui ne fonctionnera jamais en ligne.

À ne jamais faire

<a href="C:\Inetpub\wwwroot\test.html"> — Ce chemin ne fonctionne que sur votre propre machine, jamais sur un serveur.

Chemin absolu

Commence par http:// ou / (racine du serveur). Obligatoire pour pointer vers un site externe.

Copier<a href="https://www.example.com/page.html">Site externe</a> <a href="/images/photo.jpg">Depuis la racine</a>

Chemin relatif

Chemin par rapport au répertoire courant de la page. Le .. signifie répertoire parent, le . signifie répertoire courant.

Copier<a href="page2.html">Même dossier</a> <a href="dossier/page.html">Sous-dossier</a> <a href="../index.html">Dossier parent</a> <a href="../images/img1.png">Image dans dossier parent</a>

03 — Types de liens

Les différents types de liens

📄
Page interne
Vers une autre page du même site — utiliser des chemins relatifs
⚓
Ancre (même page)
Vers un endroit précis de la page courante avec #id
🌐
Site externe
Vers un autre site — chemin absolu avec https:// obligatoire
📧
Email
Ouvre le client mail avec mailto:
📞
Téléphone
Utile sur mobile avec tel:
📥
Téléchargement
Force le téléchargement avec l'attribut download

Lien vers une page interne

Copier<!-- Même répertoire --> <a href="page2.html">Lien vers page 2</a> <!-- Dans un sous-dossier --> <a href="dossier1/page1.html">Texte du lien</a> <!-- Dossier parent --> <a href="../index.html">Retour à l'accueil</a> <!-- La balise <a> peut contenir d'autres balises --> <a href="page2.html"> <div> <p>Tout ce bloc est cliquable.</p> </div> </a>

Ancre dans la même page

Utile pour les pages longues : on définit d'abord une ancre avec l'attribut id, puis on crée un lien vers elle avec #.

Copier<!-- 1. Définir l'ancre cible --> <a id="chapitre2"></a> <h2>Chapitre 2</h2> <!-- 2. Créer le lien vers l'ancre --> <a href="#chapitre2">Aller au chapitre 2</a> <!-- Ancre par défaut : haut de page --> <a href="#top">Retour en haut</a> <!-- Ancre dans une autre page --> <a href="page.html#chapitre2">Page + ancre</a>

05 — CSS

Pseudo-classes CSS pour les liens

Une pseudo-classe est un mot-clé ajouté à un sélecteur pour cibler un élément dans un état spécifique. Syntaxe : sélecteur:pseudoclasse { ... }

Ordre obligatoire

Pour les liens, les pseudo-classes doivent être déclarées dans cet ordre précis : :link → :visited → :hover → :focus → :active

a:link
Lien non encore visité
a:visited
Lien déjà visité
a:hover
Curseur de la souris au-dessus
a:focus
Lien ciblé au clavier (Tab)
a:active
Au moment du clic
p:first-letter
Première lettre d'un paragraphe
Copier/* Styles des liens dans l'ordre correct */ a:link { color: red; text-transform: uppercase; } a:visited { color: blue; text-decoration: underline; } a:hover { font-weight: bold; font-style: italic; } a:active { text-decoration: underline overline green; } /* Pseudo-classes d'insertion */ .tel:before { content: '✆ '; } .mail:after { content: ' 📧'; } a:hover:before { content: '⇨'; } /* Première lettre d'un paragraphe */ p:first-letter { font-size: 1.5em; color: blue; }
