Les images en HTML & CSS

La balise <img>

Insérez et stylisez des images, comprenez les formats web, gérez l'opacité, les dimensions et l'alignement avec CSS.

// insérer une image
<!-- Syntaxe de base -->
<img
  src="./images/photo.jpg"
  alt="Description"
  width="100%"
/>

<!-- Avec légende -->
<figure>
  <img src="photo.jpg"
       alt="Paysage"/>
  <figcaption>
    Un beau paysage
  </figcaption>
</figure>

01 — Introduction

Les balises orphelines

Certains éléments HTML ne sont constitués que d'une seule balise, appelée balise orpheline. C'est le cas des éléments qui n'ont pas de contenu textuel, comme <br> ou <img>.

Copier<br /> <!-- Retour à la ligne --> <hr /> <!-- Ligne horizontale --> <img src="..." /> <!-- Image -->
À retenir

Les balises orphelines n'ont pas de balise fermante. Le / de fin (<img />) est facultatif en HTML5, mais recommandé pour la lisibilité.

02 — La balise img

Insérer une image

L'insertion d'une image est obtenue par la balise <img>. C'est une balise de type en ligne (inline) : les images se collent les unes aux autres en fonction de leurs dimensions.

Copier<!-- Chemin relatif --> <img src="./images/photo.png" alt="Description"> <!-- Chemin absolu (externe) --> <img src="https://www.site.com/img.png" alt="Description"> <!-- Image cliquable (dans une balise <a>) --> <a href="paysage.jpg" target="_blank"> <img src="paysage-mini.jpg" alt="Voir en grand"> </a>
Aperçu — image cassée (lien mort)
🖼️ ✕

Si le chemin src est incorrect, une icône d'image cassée s'affiche à la place.

03 — Attributs

Les attributs essentiels

AttributRôleObligatoire ?
srcChemin vers le fichier image (relatif ou absolu)✅ Oui
altDescription textuelle de l'image (accessibilité, SEO, image cassée)✅ Oui
widthLargeur en px ou % — préférer le % pour le responsiveNon
heightHauteur en px — attention à ne pas déformer l'imageNon
titleInfobulle au survol de la sourisNon

Largeur et hauteur

Sans précision de taille, l'image prend ses dimensions naturelles. Pour une image responsive qui s'adapte à l'écran, utilisez width="100%" plutôt qu'une valeur en pixels.

Copier<!-- Taille fixe en pixels --> <img src="photo.jpg" alt="Photo" width="300px" height="200px"> <!-- Responsive : s'adapte à la largeur du conteneur --> <img src="photo.jpg" alt="Photo" width="100%">
Attention à la déformation

Si vous définissez width et height en même temps avec des proportions différentes de l'original, l'image sera déformée. Définissez de préférence uniquement la largeur — la hauteur s'adaptera automatiquement.

L'attribut alt est obligatoire

Il sert de texte de remplacement si l'image ne charge pas, aide les moteurs de recherche à indexer les images, et est lu par les liseuses d'écran pour les personnes malvoyantes.

04 — Formats

Formats et poids des images

Pour que le téléchargement soit rapide, il faut utiliser des formats compressés. Évitez le BMP, beaucoup trop lourd.

GIF
256 couleurs Animation Transparence

Logos, icônes, animations simples. Palette de couleurs très limitée.

JPG
16.7M couleurs Animation Transparence

Idéal pour les photos. Compression avec perte de qualité progressive.

PNG
16.7M couleurs Animation Transparence

Recommandé par le W3C. Compression sans perte. Meilleur compromis GIF/JPG.

Taille recommandée

Pour un fond de site pleine page : 1920 × 1080 px. Une photo d'appareil photo fait 4–8 Mo — utilisez GIMP ou Paint.net pour la compresser avant intégration.

Miniature cliquable

Pour les images lourdes, affichez d'abord une miniature cliquable qui ouvre l'image en grand dans un nouvel onglet.

Copier<a href="paysage-original.jpg" target="_blank"> <img src="paysage-mini.jpg" alt="Voir le paysage en grand"> </a>
05 — Sémantique

<figure> et <figcaption>

L'élément <figure> est un conteneur sémantique multimédia qui indique aux moteurs de recherche que l'image est importante pour la compréhension du contenu. <figcaption> ajoute une légende visible.

Copier<figure> <img src="./images/paysage.jpg" alt="Paysage de montagne enneigée" title="Paysage de montagne" width="100%" /> <figcaption>Un paysage de montagne — Alpes, 2024</figcaption> </figure>
Rôle sémantique

<figure> peut contenir d'autres médias : <video>, <audio>, ou même du code. La légende <figcaption> peut se placer avant ou après l'image.

06 — CSS Background

Image d'arrière-plan

La propriété CSS background-image permet d'ajouter une image en fond d'un élément HTML. Elle s'utilise quand l'image est purement décorative et n'apporte pas de sens au contenu.

Règle importante

On ne met jamais en fond une image porteuse d'information. Ces images se mettent dans le HTML avec un alt approprié. Une image en fond n'a pas de texte alternatif.

Copier/* Image de fond simple */ body { background-image: url('./images/fond.jpg'); background-repeat: no-repeat; background-size: cover; background-position: center center; background-attachment: fixed; } /* Plusieurs images superposées */ div { background-image: url('calque1.png'), url('calque2.png'); } /* Couleur de secours si l'image ne charge pas */ section { background-image: url('fond.jpg'); background-color: #1a1208; /* s'affiche en dessous */ }
background-repeat
repeat, repeat-x, repeat-y, no-repeat — définit si l'image se répète
background-size
cover (recadre), contain (tout visible), ou valeur en px/%
background-position
top, center, bottom left… ou valeurs en px/%
background-attachment
fixed pour un effet parallaxe, scroll (défaut)
07 — Styles CSS

Styles CSS sur les images

L'opacité

La propriété opacity gère la transparence d'une image ou de n'importe quel élément HTML. Valeur entre 0 (invisible) et 1 (opaque).

Copierimg.opacite { opacity: 1; /* Complètement visible */ } img.opacite:hover { opacity: 0.5; /* Semi-transparent au survol */ }
Démo interactive — survolez les blocs
opacity: 1
0.7
0.4
0.1

Survolez un bloc pour voir l'effet opacity: 0.5 au hover.

Important

Une image avec opacity: 0 (complètement transparente) reste présente dans la page et garde sa position. Elle est invisible mais occupe toujours de l'espace.

Dimensions en CSS

Les propriétés width et height existent aussi en CSS et s'appliquent à tous les éléments. Si une seule propriété est définie, l'autre s'adapte automatiquement en respectant les proportions.

Copier/* Taille fixe */ #img-fixe { width: 200px; } /* Responsive avec limite minimale */ #img-responsive { width: 50%; min-width: 200px; /* Jamais moins de 200px */ max-width: 800px; /* Jamais plus de 800px */ } /* Boîte fixe sans déformation avec object-fit */ #img-boite { width: 200px; height: 200px; object-fit: cover; /* Recadre sans déformer */ }

Alignement vertical — vertical-align

La propriété vertical-align définit l'alignement des éléments inline (comme <img> et <span>) par rapport à la ligne de base (baseline).

Copierimg { vertical-align: baseline; /* défaut */ } img.milieu { vertical-align: middle; /* centré verticalement */ } img.haut { vertical-align: top; /* aligné en haut */ } img.bas { vertical-align: bottom; /* aligné en bas */ }
Rappel inline

Un élément inline prend uniquement la place nécessaire à son contenu, ni plus ni moins. Les images (<img>) et les <span> sont des éléments inline par défaut.
